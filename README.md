# POS , Inventory and E-Commers Management System 

A complete POS & Inventory Management System built with PHP and MySQL. Manage products, suppliers, categories, stock, sales, and generate reports — all from a single admin panel.

## ✨ Features

- 📦 **Product Management** — Add, edit, delete, and view products with images
- 🏷️ **Category Management** — Organize products by categories
- 🚚 **Supplier Management** — Manage supplier information and contacts
- 📊 **Stock Tracking** — Real-time inventory updates
- 💰 **Sales & Purchase Records** — Track all transactions
- 📈 **Reports & Analytics** — Generate detailed reports
- 🔐 **Admin Panel** — Secure login system for administrators
- 🔍 **Search & Filter** — Quickly find products, suppliers, or categories
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile
